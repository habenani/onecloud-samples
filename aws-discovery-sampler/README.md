# AWS discovery sampler

One small deployment with one of each AWS resource type OneCloudify records in the CMDB. Use it to check how your instance records each type after an apply: written from the Terraform state, confirmed by targeted pattern discovery where the resource type map names a pattern, or kept in the generic Cloud Resource class when the type has no mapping. Order it, read the CMDB and Discovery steps on the run, then Remove it.

What it creates (eu-north-1 by default, nothing reachable from the internet): a VPC with two subnets in two zones, a security group, an Amazon Linux 2023 `t3.micro` instance with a 1 GB gp3 data volume, an internal application load balancer, an RDS PostgreSQL `db.t3.micro` instance (20 GB, no backups, no final snapshot, password generated by Terraform and kept only in the state) with its subnet group, and a CloudWatch log group (a type with no mapping, so it lands in the generic class, as does the database subnet group).

Cost: the database and the load balancer are billed by the hour. Creating and deleting the database takes about 5 to 10 minutes each way; do not keep the deployment longer than the check.

Permissions: the OneCloudify identity needs Elastic Load Balancing and RDS create and delete rights in the region (statement LoadBalancersAndDatabases of `cloud-bootstrap/aws-bootstrap.yaml` in the OneCloudify repository).

## What the requester fills in

| Variable | Notes |
|---|---|
| `name` | Base name, 2 to 20 lowercase characters |
| `instance_type`, `db_instance_class` | Smallest your account allows |
| `region`, `tags`, `test_tag` | Filled by OneCloudify or left empty |

## What to check after the order

Open the run and the deployment's resources: every AWS resource has a row, mapped types have a CI of their class, types with a pattern show a Discovery status, the log group and the database subnet group sit in Cloud Resource (`cmdb_ci_cmp_resource`) and the volume attachment has no CI. The OneCloudify guide Cloud accounts and Discovery, section 9.6, lists the expected result per type.
